Getting started

Install Tidewatch and run your first scheduled task in about two minutes.

Install

Tidewatch needs Python 3.9 or newer.

pip install tidewatch

Write your first task

Create a file called jobs.py:

from tidewatch import Scheduler, task

@task(every="30s")
def heartbeat():
    print("still alive")

if __name__ == "__main__":
    s = Scheduler()
    s.add(heartbeat)
    s.run()

Then run it:

python jobs.py

You should see still alive printed every 30 seconds. Press Ctrl+C to stop.

Use a cron schedule

For calendar-style schedules, pass cron instead of every:

@task(cron="0 9 * * 1-5")   # 09:00, Monday to Friday
def morning_report():
    ...

Pass either every or cron, not both. Tidewatch raises ConfigError if you pass both.

Handle failures

@task(every="1h", retries=5, backoff=2.0)
def flaky_api_call():
    ...

With backoff=2.0, the wait doubles after each failed attempt: 1 s, 2 s, 4 s, and so on.
