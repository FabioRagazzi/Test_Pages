API reference

Everything the library exposes. In a real project, much of this page can be generated from docstrings.

Scheduler

class Scheduler(timezone: str = "UTC")

Holds a set of tasks and runs them.

ParameterTypeDescription
timezonestrIANA timezone name used for cron schedules. Defaults to "UTC".

Scheduler.add

add(fn: Callable) -> None

Registers a function decorated with @task. Raises ConfigError if the function was not decorated.

Scheduler.run

run(blocking: bool = True) -> None

Starts the scheduler. With blocking=False, it runs in a background thread and returns immediately.

task decorator

@task(every=None, cron=None, retries=0, backoff=1.0)
ParameterTypeDescription
everystr | NoneInterval such as "30s", "15m", or "2h".
cronstr | NoneFive-field cron expression.
retriesintHow many times to retry after a failure. Default 0.
backofffloatMultiplier applied to the wait between retries. Default 1.0.

Errors

ExceptionRaised when
ConfigErrorA task has no schedule, has two schedules, or has an invalid schedule string.
TaskFailedA task still fails after all retries. Logged, and the scheduler keeps running.
