Tidewatch

Run Python functions on a schedule, with retries, in one small file of code. No broker, no daemon.

This is a demo site. Tidewatch is a fictional library. These pages exist so you can see how a docs site looks when it is hosted on GitHub Pages.

A first example

from tidewatch import Scheduler, task

scheduler = Scheduler()

@task(every="15m", retries=3)
def sync_inventory():
    print("Syncing inventory...")

scheduler.add(sync_inventory)
scheduler.run()

This runs sync_inventory every 15 minutes and retries up to three times if it raises an exception.

What you get

FeatureWhat it does
Interval and cron schedulesUse every="15m" or cron="0 9 * * 1-5".
Automatic retriesFailed tasks retry with exponential backoff.
Zero dependenciesOnly the Python standard library.
